# DoBetterMoney

Personal finance tools built with React, Tailwind CSS, and shadcn/ui.

## Stack

- **Vite** + **React** + **TypeScript**
- **Tailwind CSS** v4
- **shadcn/ui** (Radix + Nova preset)

## Setup

```bash
npm install
npm run dev
```

## Add components

```bash
npx shadcn@latest add [component]
```
